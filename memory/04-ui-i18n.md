## Дизайн-система (редизайн Atompunk/Googie, 2026-11-10)
> Запрос пользователя: сделать сайт «живее», ретрофутуризм, шрифт Pixelify Sans, анимированные кнопки. Стиль — **Atompunk/Googie** (светлый), применён на **весь сайт**.

- **Шрифт:** `Pixelify_Sans` (next/font) — основной дисплейный+UI шрифт, subsets latin/latin-ext/cyrillic (en+ru). Для hy — `Noto_Sans_Armenian` (fallback, у Pixelify нет армянских глифов). Стек `var(--font-pixel), var(--font-armenian), ...` подставляет Noto только для армянских глифов (пофайлово), поэтому латиница («StudyFlow») остаётся пиксельной на всех языках. **НЕ использовать `:lang(hy)`-переопределение шрифта** — оно форсирует армянский шрифт на весь текст, включая «StudyFlow» (баг, исправлен 2026-11-10). Geist удалён.
- **Палитра (CSS-переменные в `globals.css` `:root`, НЕ фиолетовый):** `--paper` #f4e9cf (кремовый фон), `--surface` #fffaf0 (карточки), `--ink` #2b2420 (текст+рамки), `--tangerine` #f26419 (основное действие), `--teal` #11999e (вторичное/ссылки), `--mustard` #edab25, `--coral` #e23e57 (опасно/ошибки), `--sky` #2d9cdb. Токены проброшены в Tailwind через `@theme inline` → утилиты `bg-paper/surface`, `text-ink/tangerine/teal/coral`, `border-ink` и т.п. `--background`/`--foreground` сохранены (= paper/ink) для старых утилит. Dark-mode убран (стиль светлый).
- **Фон body:** лёгкая Googie-текстура (radial-dots 22px + диагональные линии), слабый контраст.
- **Переиспользуемые классы (`@layer components` в `globals.css`):** `.rf-card` (3px рамка ink + жёсткая тень `4px 4px 0`, hover-подъём), `.rf-card-hover`, `.rf-card-dashed` (пустые состояния), `.btn` + `.btn-primary/secondary/accent/danger` + `.btn-sm` (шаг на hover, вдавливание на active), `.rf-field` (инпуты/селекты/textarea, focus → teal-рамка+тень), `.rf-badge`, `.rf-navlink`/`.rf-navlink-active`. **Правило:** новые элементы оформлять этими классами, цвета — через токены, не хардкодить hex.
- **Декор:** `src/components/RetroDecor.tsx` — `Starburst` (Googie-звезда SVG) и `AtomBadge` (атом с орбитой, CSS `rf-orbit`). Используются на лендинге и экранах входа (aria-hidden).
- **Запуск превью:** `.claude/launch.json` → конфиг `studyflow-dev` (`npm run dev`, порт 3000).

## Компоненты
- `AppShell` — шапка/навигация + guard ученика (роль + членство → /pending).
- `TeacherShell` — шапка + guard учителя (не-учитель → /teacher/login). Содержит навигацию: Обзор / Ученики / Задачи (`.rf-navlink`).
- `StudentTasksView` — общий компонент страниц задач ученика (вкладки по статусу); используется в `/tasks`, `/tasks/in-progress`, `/tasks/done`.
- `AuthForm` — вход/регистрация ученика. С 2026-11-07: регистрация = имя+фамилия (одна строка), номер телефона, пароль, повтор пароля; вход = имя+фамилия (одна строка) + пароль. Клиентская проверка «пароли не совпадают» (`auth.passwordsMismatch`). Списки учеников у учителя показывают «Фамилия Имя + номер».
- `TeacherStudents` — список учеников: add/remove из класса + **onDelete (полное удаление аккаунта)**. `TeacherTasks` — форма выдачи + список задач (фильтр по ученику, удаление).
- `TaskForm` — форма задачи (используется для полей; у учителя своя форма с выбором ученика в `TeacherTasks`).
- `Badge` (`StatusBadge`,`PriorityBadge`), `LanguageSwitcher`.
- `SnakeGame` — играбельная Змейка на canvas (стрелки/WASD, еда, рост, счёт, рестарт при столкновении); фон `/pending`.

## Анимации
- Keyframes в `globals.css`: `rf-pop` (появление — классы `.rf-enter`/`-2`/`-3` со ступенчатой задержкой), `rf-float` (покачивание декора), `rf-spin`/`rf-orbit` (атом), `rf-blink`. Кнопки/карточки: шаг на hover, вдавливание на active. Всё под `@media (prefers-reduced-motion: reduce)` отключается.
- Лендинг `/`: ПЕРЕДЕЛАН — вместо чёрного рукописного «Welcome» (Caveat удалён) светлый Atompunk-герой: атом с орбитой, крупный «StudyFlow» (Pixelify), Googie-звёзды, ретро-кнопки.
- `/pending`: Змейка перекрашена в светлую палитру (кремовое поле, tangerine-змея, teal-еда), панель — `rf-card`.
