# 04 — UI и локализация

## Локализация (i18n)
- Кастомный лёгкий провайдер: `src/i18n/i18n.tsx` (`I18nProvider`, `useI18n`, `t("ключ.путь")`).
- Словари: `src/i18n/locales/en.json`, `ru.json`, `hy.json`.
- Текущий язык хранится в `localStorage` (`studyflow.locale`), по умолчанию `en`.
- Переключатель: `src/components/LanguageSwitcher.tsx` (EN / RU / ՀՅ).
- Армянский шрифт: `Noto_Sans_Armenian` подключён в layout (у Geist нет армянских глифов).
- **Правило:** новые тексты UI добавлять во все три словаря, не хардкодить в разметке.
