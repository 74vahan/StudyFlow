# 04 — UI и локализация

## Локализация (i18n)
- Кастомный лёгкий провайдер: `src/i18n/i18n.tsx` (`I18nProvider`, `useI18n`, `t("ключ.путь")`).
- Словари: `src/i18n/locales/en.json`, `ru.json`, `hy.json`.
- Текущий язык хранится в `localStorage` (`studyflow.locale`), по умолчанию `en`.
- Переключатель: `src/components/LanguageSwitcher.tsx` (EN / RU / ՀՅ).
- Армянский шрифт: `Noto_Sans_Armenian` подключён в layout (у Geist нет армянских глифов).
- **Правило:** новые тексты UI добавлять во все три словаря, не хардкодить в разметке.

## Страницы (модель «учитель → ученики»)
| Маршрут | Роль | Статус |
|---|---|---|
| `/` лендинг (чёрный фон, анимация «Welcome» рукой; ссылка «вход учителя») | — | ✅ |
| `/login`, `/register` (общий `AuthForm`) | ученик | ✅ |
| `/teacher/login` (ввод 6-значного PIN) | учитель | ✅ |
| `/teacher` (ученики: добавить/убрать; выдача/список задач) | учитель | ✅ |
| `/pending` («404/не в классе»; на фоне играбельная Змейка) | ученик без класса | ✅ |
| `/dashboard` (счётчики + последние своих задач) | ученик | ✅ |
| `/tasks` (свои задачи, поиск/фильтры, смена статуса инлайн) | ученик | ✅ |
| `/tasks/[id]` (просмотр + смена статуса) | ученик | ✅ |

`/tasks/new` удалён (ученик не создаёт задачи — их выдаёт учитель).

## Компоненты
- `AppShell` — шапка/навигация + guard ученика (роль + членство → /pending).
- `TeacherShell` — шапка + guard учителя (не-учитель → /teacher/login).
- `AuthForm` — вход/регистрация ученика.
- `TeacherStudents` — список учеников с add/remove. `TeacherTasks` — форма выдачи + список задач (фильтр по ученику, удаление).
- `TaskForm` — форма задачи (используется для полей; у учителя своя форма с выбором ученика в `TeacherTasks`).
- `Badge` (`StatusBadge`,`PriorityBadge`), `LanguageSwitcher`.
- `SnakeGame` — играбельная Змейка на canvas (стрелки/WASD, еда, рост, счёт, рестарт при столкновении); фон `/pending`.

## Анимации
- Лендинг `/`: рукописное «Welcome» (шрифт Caveat через next/font) рисуется SVG-обводкой (`stroke-dashoffset`), затем заливается белым; играет один раз и остаётся; чёрный фон; учтён `prefers-reduced-motion`.

## i18n-секции
`app, common, nav, auth, task, dashboard, pending (+play), teacher, role` — во всех 3 словарях.
