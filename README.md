# StudyFlow

Учебная платформа управления задачами для студентов: создавать задачи, следить за дедлайнами и приоритетами, видеть прогресс, получать AI-подсказку по плану шагов. Экзаменационный проект курса Vibe Coding.

## Возможности (MVP)
- Регистрация и вход; каждый пользователь видит только свои задачи.
- Задачи: создание, просмотр, редактирование, удаление (CRUD).
- Поля: заголовок, описание, дедлайн, приоритет, статус.
- Поиск по заголовку и фильтры по статусу/приоритету.
- Dashboard со счётчиками (всего / выполнено / в процессе).
- AI-помощник: из описания задачи — план из мелких шагов (Claude API).
- Интерфейс на 3 языках: English, Русский, Հայերեն. Адаптив под телефон и ПК.

## Технологии
- **Next.js 15** (App Router, TypeScript), React 19
- **Tailwind CSS v4**
- **Supabase** — Postgres, Auth, Row Level Security
- **Claude API** (`@anthropic-ai/sdk`) — AI-функция, только на сервере
- **Vercel** — деплой

## Локальный запуск
```bash
npm install
cp .env.example .env.local
# заполните .env.local своими значениями (см. ниже)
npm run dev
```
Откройте http://localhost:3000

## Переменные окружения
Описаны в [`.env.example`](.env.example). Реальные значения хранятся только в `.env.local` (в git не попадают).

| Переменная | Назначение | Где используется |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | URL проекта Supabase | браузер + сервер |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | публичный (anon) ключ | браузер + сервер |
| `SUPABASE_SERVICE_ROLE_KEY` | секретный ключ (по умолчанию пусто) | только сервер |
| `ANTHROPIC_API_KEY` | ключ Claude API | только сервер |

> Секреты никогда не коммитятся. В репозитории — только `.env.example` с пустыми значениями.

## Деплой (Vercel)
1. Залить приватный репозиторий на GitHub.
2. Импортировать проект в Vercel.
3. Задать те же переменные окружения в настройках Vercel (Production).
4. Проверить прод-ссылку в режиме incognito.
